## 使用规则

1. **开工先登记**：在「进行中」表加一行（任务、会话标识、文件范围、独占资源）；结束把状态改 ✅ 并在「已完成」留档交付物（部署 id / commit）；
2. **独占资源**：`wrangler deploy`（游戏站/主站）与 `upload-games.mjs`（R2 上传器）运行期间独占——其他会话不得并发部署、不得改 `games.json` / `games.en.json`；登记撤销即释放；
3. **跨会话交接挂「待认领」**：写清事项与验收标准，认领者把会话标识写进表格——跨流水线的工序不许口头交代（EN 元数据欠账的教训）；
4. 冲突事故修完后在页末「冲突事故复盘」补记根因与改进。
