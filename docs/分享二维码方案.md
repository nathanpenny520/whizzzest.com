# 分享二维码 —— 页脚「分享本站」艺术码盲盒方案

> 文档版本：**v1.0** ｜ 2026-09-09 ｜ 状态：**已实施·本地验收通过·待部署**（真机微信实测待做，见 §6）
> 决策⑮（2026-09-09）：页脚新增「分享本站」入口——4 张 AI 艺术二维码加权随机盲盒（傩面少女 w=4，余各 w=1）+ 必备下载功能 + 微信长按路径。素材源 `whizzzest_QRcode/` 四张 1152² PNG，站点侧统一转 800² JPG。

---

## 1. 需求与定位

页脚加一个分享功能：点击弹出站点二维码供扫码/保存/下载分享。四张艺术码（雪山星夜 / 白发红衣女 / 白裙夜景女 / 黑衣鬼面少女）均解码为 `https://whizzzest.com`（zxing-cpp 实测），本质是同一 URL 的四种画风，因此交互定为**每次点击加权随机出一张**（盲盒感，重复点可换图），而非四选一的选择器。

用户核心要求：**二维码必须可下载**，否则起不到分享效果。

## 2. 交互设计

- **入口**：页脚社交图标行（`.footer-social`）首位加一枚 QR 造型图标按钮（`share-site`），与既有图标视觉一致。
- **灯箱**（复用全站 `#lightbox`）：

```
┌──────────────────────┐
│      [艺术二维码]      │   ← 加权随机一张，展示 -800.webp
│   扫码访问 whizzzest.com │   ← data-cap
│ 微信内长按识别二维码，或    │
│ 保存/下载图片后分享        │   ← t.footer.shareHint
│ [下载二维码]  [换一张]    │   ← 焰色胶囊主按钮 + 灰色次按钮
└──────────────────────┘
```

- **加权随机**：傩面少女 w=4（约 57% 概率，傩面元素与开口傩非遗内容最搭），其余三张各 w=1。「换一张」排除当前图重抽（必换图）。
- **下载**：`<a download="焰境万载-分享二维码.jpg">` 指向同源 **JPG 原图**（非 WebP 变体，通用格式 + 中文重命名，转发的图二次扫码仍成立）。
- **微信路径**：微信内置浏览器不支持 `download` 属性，点击下载会打开原图——恰好落回「长按识别 / 长按保存」的原生路径，由提示行明示。两条分享链路都通。
- **模式隔离**：视频号/公众号两个既有单码按钮走原 `openLb` 直开，分享操作区不出现；关灯箱即复位（操作区隐藏、下载链接清空）。

## 3. 技术实现

数据流：`site.json`（中英各一份）`footer.socials[]` 新增 `qrList` 条目 → build.js 校验并序列化 → 模板输出 `data-qr-list` 属性 → main.js 运行时 `JSON.parse` 后按 `item.w`（缺省 1）加权随机。

| 文件 | 改动 |
| --- | --- |
| [build.js](../build.js) | `SOCIAL_ICONS` 注册 `share-site` QR 造型图形（evenodd 挖孔）；socials 循环校验三条件（href/qr/qrList 缺一即 throw）、预计算 `isLink/isQr/isShare` 三态布尔（模板引擎条件仅支持单路径真值）、`qrList` 序列化 `qrListJson` |
| [src/data/site.json](../src/data/site.json) / [en/site.json](../src/data/en/site.json) | `socials` 首位加分享条目（傩面 w=4）；中英 label/cap 各自本地化 |
| [src/partials/footer.html](../src/partials/footer.html) | 社交图标 `#if/#unless` 双分支改 `isLink/isQr/isShare` 三分支（share 分支输出 `data-qr-list`）；灯箱新增 `.lightbox-share` 操作区（`hidden` 起步，无 JS 零影响） |

## 4. 素材解码验证（桌面解码器下限测试）

艺术码在桌面解码器（zxing-cpp）比手机引擎（微信/相机）严格，以下为**下限**验证——全档位通过方才入站。方法：多尺度（原图→320）+ CLAHE + 7 档二值化穷举。

| 文件 | JPG 原图 | -800.webp（展示档） | -480.webp |
| --- | --- | --- | --- |
| qr-share-nuomian | ✅ | ✅ | ✅ |
| qr-share-snow | ✅ | ✅ | ✅ |
| qr-share-hongyi | ✅ | ✅ | ✅ |
| qr-share-baiqun | ✅ | ✅ | ✅ |

> 曾试验：JPG q88 直出后窄阈值解码 3/4 失败，是验证方法覆盖不足而非图损——扩阈值后全过。**换图时必须跑同一套穷举解码**（源码见本文档 git 历史）。
