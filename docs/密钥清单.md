# 密钥清单（docs/全站优化方案.md W7 交付物）

> **只记名称与用途，永不记值。** 值只存在于 Cloudflare 后台（wrangler secret）、GitHub 仓库机密、本地 `.dev.vars`（不入库）。收编自原 4 个 wrangler.jsonc 注释里的分散说明。

## 线上密钥（Cloudflare 后台 → Workers → 对应 Worker → Settings → Variables）

| 密钥 | 用途 | 所属 Worker |
| --- | --- | --- |
| `ADMIN_PASSWORD` | 后台主账号（站长）密码 | admin |
| `ADMIN_SESSION_SECRET` | 后台会话签名（含 WebAuthn challenge 签名） | admin |
| `MERCHANT_SESSION_SECRET` | 商户门户会话签名 | merchant |
| `WRITER_SESSION_SECRET` | 作者门户会话签名 | writer |
| `SMTP_USER` / `SMTP_PASS` | 发邮件：门户邮箱验证码、联系表单企业邮通知 | writer / merchant / 主站共用 |
| `NOTIFY_TO` | 联系表单通知的收件邮箱 | 主站 |

## 平台凭证（不在代码、不在 wrangler secret）

| 凭证 | 用途 | 存放 |
| --- | --- | --- |
| `CLOUDFLARE_API_TOKEN` | GitHub Actions 部署 4 个 Worker | GitHub 仓库 → Settings → Secrets and variables → Actions |
| Cloudflare 账号登录 | wrangler 本地操作（部署 / d1 execute / export） | 本机 `wrangler login` 的 OAuth（当前为 nathanpenny@qq.com 账号） |

## 本地开发（各 Worker 目录 `.dev.vars`，已 gitignore）

与上表同名：本地调试用明文。本地 D1 为独立库，与线上无任何连接（**本地永不直连线上数据库**，对生产数据的操作走后台界面或明确的一次性操作）。

## 三条制度

1. **部署 Token 最小权限**：`CLOUDFLARE_API_TOKEN` 只授权 4 个 Worker 的部署权限，不用账号级全域 Token（现有 Token 权限待在 Cloudflare 后台复核一次）；
2. **会话密钥轮换预案**：改 `*_SESSION_SECRET` = 对应门户**全体下线**需重新登录（特性也是风险）；轮换选低峰期并提前公告；ADMIN_SESSION_SECRET 还承担 Passkey challenge 签名，轮换后已注册通行密钥仍可用（凭据在 D1），仅进行中的登录流程会失败；
3. **密钥不进文档 / 截图 / 聊天记录**：发现文档里有值立即作废轮换。
