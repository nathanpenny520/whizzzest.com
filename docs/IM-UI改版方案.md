### 2.1 icon 栏（~64px，--panel）

上：💬聊天 / 👥联系人 / ⚙设置（当前态 `--panel-on` 高亮）；下：我的头像（点开=设置）+ 退出登录。移动端 ≤720px 转为底部 tab 条。

### 2.2 会话列表面板（~400px，两态）

**聊天态**（默认）：头部「焰境密语」+ ⊕（开新聊→联系人态）+ ⋮ 菜单（设置/退出登录）→ 搜索框（本地过滤会话）→ 筛选 chips：全部/未读/群组（本地过滤）→ 会话行：头像 49px 圆 + 名 + 预览（单行省略）+ 右侧时间（今天 HH:MM，更早 M/D）+ 未读胶囊（--brand）；行 hover `--panel-hi`、选中 `--panel-on`；空态分筛选给文案。**好友申请横幅**（pendingIn>0 时）：`--panel-on` 底、可点直达申请页。
**联系人态**（WhatsApp「新聊天」面板式）：←返回 + 标题 → 入口行（新群聊/添加好友/好友申请 N）→ 好友列表（行点击=开私聊；行尾拉黑/删除小按钮 hover 显形，保留原逻辑）；申请/添加/建群为面板内子页（←返回层层退），逻辑全部沿用现 contacts.js。

### 2.3 聊天主区

- **头部**：←（移动端）+ 头像 38px + 名 + **状态副标**（1v1：在线/离线/重连中/**「对方正在输入…」**；群：N 人 · M 在线/「张三、李四正在输入…」）+ ⓘ信息按钮（开抽屉）+ ⋮菜单。dm ⋮：联系信息(开抽屉)/拉黑/删除好友/举报；群 ⋮：群信息(开抽屉)/修改群名(群主)/解散(群主)/退出群聊。**安全数字从头部移入 dm 信息抽屉**（M4 语义不变）。
- **消息流**：doodle 壁纸；日期胶囊（今天/昨天/M月D日）；**气泡带尾巴**（CSS 伪元素，发出的右尾焰红、收到的左尾）；系统消息居中细条（沿用）；**未读分割线**：进入会话时若有未读（`last_read_seq` 已有），在首个 `seq > last_read_seq` 的行前插「未读消息」蓝色（--accent）细线；
- **群消息**：发送者名彩色（按 avatar_color 色相）+ 收到气泡左侧 18px 小头像；
- **气泡 meta**：时间 + 回执内嵌气泡右下（发出：时间 + ✓/✓✓；发出中：🕐；失败：红 ✕ + 原有 fail 样式；收到：仅时间）；
- **输入条**：圆角胶囊容器（textarea 自动伸缩 ≤96px，回车发送 Shift+回车换行——现状即如此）+ 圆形发送键（--brand，空文本时置灰）。

### 2.4 信息抽屉（.im-info，聊天区内右侧 340px 列）

- **dm**：大头像 + 名 + UID → **安全数字块**（等宽 6 组 + 复制按钮 + 核验说明）→ 操作列表（拉黑/取消拉黑、删除好友、举报——与 ⋮ 菜单共用同一批动作函数）；
- **群**：群头像 + 群名 + 成员数 → 成员列表（现 members.js 渲染迁入：群主拉人多选/移出/逐员指纹）→ 操作（修改群名(群主)/举报/退出群聊/解散群聊）；
- 桌面为聊天区右列（消息区收窄）；移动端全屏覆盖层 + ✕ 关闭。

### 2.5 设置视图（主区，替代现欢迎三卡片）

WhatsApp 设置页式：头像大图（首字+色）+ 昵称/简介/头像色编辑（沿用原保存逻辑）→ 账号卡（UID/手机/邮箱/注册时间）→ 加密身份卡（算法/公钥指纹/密码备份状态/本机密钥状态徽标）→ 退出登录。入口：icon 栏 ⚙ / 列表面板 ⋮ / rail 头像。

## 4. ✓✓ 已读回执（唯一服务端改动，1v1 生效）

- **数据**：`im_members.last_read_seq` 已有，无迁移；
- **API**（`src/api/convs.js`）：`convsList` 增子查询取 dm 对方 `last_read_seq`（仅 dm 会话在响应中带 `peer_last_read`）；`convRead` 在 `seq > 现值` 时才 UPDATE + 经 `notifyRoom` 广播（避免无谓 DO 调用）；
- **DO 帧**（`src/do/room.js`）：`/sys` 复用，广播 `{t:'read', uid, seq}`（成员信不信沿用现有模型）；
- **前端**：`chat.js` 开会话取 `conv.peer_last_read` 渲染历史回执；收 `read` 帧且 `uid===peer.uid` 时更新本会话全部己方气泡回执（✓→✓✓，`--read` 色）；发出中 🕐、tag 回显 ✓、失败红 ✕（帧协议已在 err 帧处理）；群聊不渲染回执；
- **文档同步**：主方案 §5 帧协议补 `read` 帧、§6 API 行补 `peer_last_read` 说明。

## 8. 移动端 WhatsApp 化 v2.1（2026-09-14 业主拍板，待实施）
