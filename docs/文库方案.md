## 1. 架构（对标商户功能，全链路复用）

```
作者：writer.whizzzest.com（新 Worker whizzzest-writer）
  注册(手机号+密码) → 新建作品(封面/分类/笔名/简介) → 写章节(图文) → 提交
  ↓ books/book_chapters (pending)
站长：admin「文库」Tab —— 作品审核 + 章节审核两个队列，预览后通过/驳回
  ↓ approved
读者：whizzzest.com/library/ 三页（书架 → 详情 → 阅读页），D1 权威动态渲染
媒体：复用 R2 桶 whizzzest-media（封面 book/c-*.jpg、插图 book/b<id>/*.jpg），
      主站 /media/ 代理零改动直读；writer Worker 直挂 MEDIA 绑定上传
```

**账号隔离**：writer_users 与 merchant_users 完全独立（同手机号两边各注册各登录）；会话 Cookie `wr_session` 用独立密钥 `WRITER_SESSION_SECRET`。

## 2. 数据模型（D1，2026-09-06 迁移）

```sql
books        id, slug(b<id> 审核通过生成), title, category(novel|story|essay|other),
             intro, cover(R2键), author_name(展示笔名), writer_id(可空=admin创建),
             status(pending|approved|rejected|hidden), reject_reason, sort_weight,
             chapter_count, word_count(冗余，章节变更时重算), views,
             created_at, updated_at
book_chapters id, book_id, idx(1起), title, body(分段纯文本,[图]占位),
             images(JSON数组:R2键列表), status(pending|approved|rejected|draft), reject_reason,
             word_count, created_at, updated_at
writer_users id, phone(UNIQUE), email(UNIQUE), pass_hash, pass_salt, created_at
```

**审核模型**（解决「连载每发一章全站下线」问题）：
- 作品级：新建/元数据修改 → 整本 pending（书架不可见）；通过 → 上线
- 章节级：新增/修改章节 → 该章 pending；**已上线作品不受影响**，新章审过才可读；详情页目录显示「N 章更新审核中」
- 草稿（v1.2）：「保存草稿」→ 该章 `draft`，不进审核队列、读者不可见，也不计入作品章节数/字数冗余与「最近更新」；draft 章再提交 → pending。已上线/审核中章节转草稿视为暂时下线/撤回，UI 红字明示
- 删除章节不触发审核（不产生新内容），即时生效
- admin 直接创建的作品默认 approved 免审

## 3. 正文格式（Markdown 白名单渲染，零依赖，天然免疫 XSS）

正文 = **Markdown 纯文本**（v1.2 起编辑器聚焦文字写作，插图 UI 已撤）：支持 `#` 标题、`**粗体**`、`*斜体*`、`` `行内码` ``、``` ``` 代码块``` ``（块内空行保留）、`>` 引用、`-`/`1.` 列表、`---` 分隔线、`[文字](链接)`（只放行 http(s) 与站内相对路径，外链 `noopener nofollow`）、空行分段、段内换行 `<br>`。

渲染（worker/library.js `mdBlocks`）：**esc-first**——先整篇 HTML 转义再按白名单语法生成标签，天然免疫 XSS；`#`→`<h2>`（页面 h1 是章题）至 `######` 封顶 `<h4>`。存储仍是纯文本，旧纯文本内容按 Markdown 渲染完全等价，零迁移。worker 与 writer 编辑器预览为**同一套规则的双份实现**（零依赖不共享模块），改语法必须两处同步。

旧图文格式兼容：`[图]` 独立成段仍按 `images` 顺序渲染 `<figure>`（存量有图章节照常显示）；`image_plan`/figures 提交管线后端保留休眠（编辑器不再发送，更新时不传新文件即保留原插图），随时可恢复图文连载。

## 4. 页面

**writer.whizzzest.com**（照抄商户门户骨架，服务端渲染 + 表单流）：
`/register` 注册 · `/login` 双方式登录 · `/dashboard` 作品台（各状态卡片 + 章节数/字数 + 驳回原因可见 + 账号安全绑定邮箱）· `/book/new` 与 `/book/<id>/edit` 作品元数据 · `/book/<id>/chapters` 章节列表 · `/book/<id>/chapter/new|<cid>` 章节编辑器

**主站 /library/**（worker/library.js，getChrome 复用页头页脚）：
- 书架 `/library/`：2:3 封面网格 + 分类 Tab（?cat=）+ 最近更新排序 + ?q= 搜索（标题/简介）
- 详情 `/library/<slug>/`：封面 + 笔名/分类/字数/更新时间 + 简介 + 章节目录（仅 approved，pending 数提示）+ JSON-LD
- 阅读 `/library/<slug>/<n>/`：限宽排版（行距 1.9）+ 章内插图 + 上一章/目录/下一章 + 浏览计数
- `/library/sitemap.xml` 动态片段；robots 补充

**admin「文库」Tab**：作品列表（状态筛选/封面缩略/审核操作/编辑信息含封面/删除级联）+ **待审章节队列**（通过/删除+原因）+ **章节直改**（v1.2：编辑序号/标题/正文、删除单张插图，不改审核状态，已上线即时生效）+ admin 新建作品（免审直发）

## 5. 安全

UGC 人工审核兜底（先读后审）；正文白名单渲染免疫 XSS；图片魔数校验；作者门户整域 noindex + PBKDF2 10 万次 + 登录/注册/发码 IP 限流 + Honeypot + Origin 校验；驳回原因回传作者。
