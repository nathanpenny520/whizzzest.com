# 数字烟花方案（v1.0）

> 2026-09-06 · 烟花导航下新增互动体验页 `/digital-fireworks/`

## 1. 定位与决策

- **独立 URL** `/digital-fireworks/`，站点导航「烟花」下拉第 3 项（烟花产业 → 赏烟地点 → **数字烟花** → 烟花视频）。
- **沉浸式形态（A）**：保留站点 sticky 导航（亮色导航 + 深色画布），画布铺满导航以下整个视口；本页无页脚、不滚动（`body.page-sim { overflow: hidden }`）。
- **文字烟花保留**：默认词改站点短词；字体走系统回退（3.7MB 华文琥珀不搬运，见 §4）。
- **纯前端静态页**：无 D1、无 Worker 改动；走 build.js 静态构建，自动进 sitemap。

## 2. 模块结构

14 个零依赖 JS（globals 按脚本顺序协作，build.js 拼接）+ 444 行 CSS + 9 个音效 mp3（约 240KB）+ Russo One woff2（16KB）。

```
src/assets/js/fireworks/
  lib 部分       fscreen（全屏兼容）→ stage（双画布+Ticker+指针）→ my-math（工具）
  app 部分       config（常量/选择器/帮助文案）→ store（localStorage 状态机）
               → background-library（本地上传图片库，IndexedDB）→ background-manager（自定义背景）→ ui（DOM 查询/渲染/绑定）
  fireworks 部分 runtime（全局态/背景解析）→ shells（13 种弹型）→ interaction（指针/热区/速度条）
               → simulation（粒子/文字烟花采样）→ audio（WebAudio 合成音效）→ engine（启动装配）
```

控制方式：点击/拖拽画布发射；画布顶部 50px 三个隐形热区（暂停/声音/设置，与可见按钮对位）；画布底部 44px 拖拽调速；快捷键 P 暂停、O 菜单、Esc 关菜单。所有指针事件挂在 `document` 上（stage.js），坐标映射回画布。

## 4. 改造点

1. **`config.js`**：`storageKey` → `whizzzest_fireworks_data`；`defaultWords` → `["焰境万载", "花炮之乡", "一朝相逢"]`；`wordFontFamily` → `"华文琥珀, PingFang SC, Microsoft YaHei, sans-serif"`（本地装了华文琥珀则用之，否则系统字体采样，文字烟花照常）。
2. **`audio.js`**：`baseURL` → `/assets/audio/fireworks/`。
3. **`interaction.js` `handleResize()`**：画布高度扣除导航高度（动态读 `.nav` offsetHeight），否则画布比可视区高 48px、底部速度条被裁。
4. **`stage.js` 鼠标/触摸 handler**：开头加 `event.target.closest('.fw-app')` 守卫 —— 指针事件挂在 document 上，站点导航在画布上方，点击 logo（视口左上角）会映射成画布负坐标命中「暂停热区」，必须拦掉。
5. **CSS**：`.container` → `.fw-app`（站点已有 `.container`）；`.btn` → `.fw-btn`（站点已有 `.btn`）；`* { position: relative }` 收窄为 `.fw-app, .fw-app *`；body 级样式挂 `body.page-sim`；`.fw-app` 高度 `calc(100dvh - var(--nav-h))`；Russo One @font-face 保留（路径指向 `../fonts/fireworks/`），华文琥珀 @font-face 移除。
6. **UI 文案**：设置面板不展示版权/署名信息（2026-09-07 应站点要求移除 credits 区块，连带删除 config 的 `copyrightYear` 选择器与 engine 的 `applyStaticText`）。
7. **`head.html`**：`theme-color` 改 `{{page.themeColor}}`，buildPage 默认 `#fbfbfd`，本页传 `#000000`。

## 8. 风险与已知限制

- **CSP `img-src 'self' blob: data:`（现 Report-Only）**：设置里「自定义背景」填外链图片将来转正式 CSP 会被拦（渐变、本地上传的 blob/缩略图 data URL 不受影响，`_headers` 已预留 `blob: data:`）。转正式时外链图需提示不支持。
- **声音**：浏览器自动播放策略，首次交互后才出声（soundManager.registerInteraction 已处理 resume）。
- **音效预加载**：进页即 fetch 全部 9 个 mp3（约 240KB）；失败不影响画面（init 有 catch）。
- **文字烟花字形**：无内嵌中文字体，按访客系统回退。
- **并行会话**：提交时精确 add（烟花相关文件 + build.js + site.json + head.html + docs）。

## 10. v1.1：自定义背景本地上传（2026-09-07）

设置面板「自定义背景」在原有地址/渐变输入之外，支持把图片直接上传保存到浏览器本地，多图缩略图画廊点选。

- **存储**：IndexedDB 库 `whizzzest_fireworks_bg` v1（store `images`，keyPath `id`）。记录 `{ id(uuid), name, thumb(data URL), blob, width, height, createdAt }`；localStorage（`whizzzest_fireworks_data` 的 `background`）只存选中 id（`mode: "library"`），图片本体不进 localStorage。
- **压缩**：上传即经 canvas 重编码——最长边 1920px、`toBlob('image/webp', 0.85)`（不支持时浏览器自动回退 PNG），缩略图 160px JPEG data URL；解码优先 `createImageBitmap`，失败回退 `Image` + objectURL。限制：单图 ≤30MB、库存 ≤12 张。
- **应用**：`background-manager.applyLibraryImage(record)` 从 blob 生成 objectURL 设为背景（`center/no-repeat/cover`），manager 统一持有并 revoke 当前 objectURL（防泄漏）；沿用 requestId 竞态守卫。
- **恢复链**：启动 `applyResolvedBackground()` → 用户背景且 `mode==="library"` → IDB 取记录 → 应用（状态「正在使用保存的背景图」）；记录丢失（清了浏览器数据）→ 标记未配置 → 回退代码默认背景/无背景。
- **画廊 UI**：`ui.renderBackgroundGallery` 渲染 4 列缩略图网格（选中蓝框 `#09f` + 右上 × 删除钮，事件委托），`runtime` 持列表缓存 + 渲染守卫（仅条目/选中变化才重建 DOM）；删除当前选中图 = 清背景回默认。
- **CSP**：`_headers` `img-src` 已扩 `blob: data:`（Report-Only 阶段无影响，转正式时已就绪）。
- **已知限制**：纯本地存储——换浏览器/设备不跟随，清除站点数据即删（帮助文案已注明）；不支持本地存储的浏览器画廊隐藏、上传报错提示。
