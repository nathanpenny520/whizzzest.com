## 一、万载音乐 `/music/`

类音乐软件播放器单页，主站 Worker 动态渲染（`worker/music.js`）。

### 页面形态

- 焰棕深色影院风（`.music-page` 全页渐变，对齐 `.tv-page`）
- 桌面双栏：左「正在播放」面板（1:1 大封面 sticky 跟随）+ 右曲目列表（行：序号/播放态 → 缩略封面 → 曲名/歌手 → 时长）
- 底部固定播放条（毛玻璃）：上一首 / 播放暂停 / 下一首 / 进度拖拽 / 时间 / 列表循环 / 音量（桌面）
- 移动端：正在播放面板变横排，音量隐藏；`body.music-body` 预留播放条高度

### 交互（main.js，单 `<audio>` 复用）

- 点击行播放 / 再点暂停；当前曲焰橙高亮 + 均衡条动画（暂停时静止）
- 自动连播 + 列表循环（可关）；进度条拖拽 seek（/media/ 已支持 Range）
- **Media Session API**：手机锁屏/通知栏显示曲名封面、可控上一首/下一首
- 播放计数：开始播放一首时 `POST /api/music/play/:id`（每首每页面只计一次，非阻塞 UPDATE）

### 数据

`music_tracks`：id / title / artist / cover / file_key / duration / sort / status(published|hidden) / plays / created_at / updated_at。
列表按 `sort, id` 排（曲序即专辑顺序）。文件键带时间戳（`music/a-<ts>-<rand>.mp3`），替换即换 URL，规避 immutable 缓存。

### 后台（admin「音乐」Tab）

- 列表：封面缩略、曲名、曲序、状态、时长、播放次数；上线/隐藏切换、编辑、删除二次确认（级联清理 R2 音频+封面）
- 表单：曲名*、演唱/演奏、状态、曲序、时长（选 MP3 后浏览器预读自动填充）、MP3*（≤50MB 流式 PUT）、封面（可选 ≤5MB 魔数校验）
- API：`GET/POST /api/music`、`POST/DELETE /api/music/:id`、`PUT /api/music/upload`、`PUT /api/music/cover`

### MP3 流式上传要点

File 直作 PUT body → Worker 只读首个 chunk 校验魔数（ID3 / MPEG 帧同步），随后经 **FixedLengthStream(len)** 把已读 chunk 接回流转发 R2——既有魔数校验又不整读内存。R2 put 要求流有已知长度，裸 ReadableStream 会被拒。

## 二、旅游景点 `/attractions/`

瀑布流推荐栏 + 详情页，主站 Worker 动态渲染（`worker/attractions.js`）。

### 页面形态

- 列表页：轻 hero + **CSS columns 瀑布流**（复用 `.masonry`：桌面 3 列 / 平板 2 / 移动 1），封面原比例错落；卡片 = 封面 + 名称 + 一句话简介 + 标签 pill
- 详情页 `/attractions/<slug>/`：面包屑 + 大封面 + 标题/标签/简介 + 信息行网格（地址/开放时间/门票/交通，有则显示）+ 分段正文（空行分段 esc 包 `<p>`，白名单防 XSS）+ 周边线路/相关视频轻关联 + 上一处/全部景点/下一处
- SEO：详情页 `TouristAttraction` JSON-LD；`/attractions/sitemap.xml` 动态片段 + 主 sitemap / robots.txt 登记

### 数据

`attractions`：id / slug*(唯一，详情 URL) / name / summary / tags(逗号分隔 ≤4) / cover / body / address / hours / tickets / transport / sort / status / created_at / updated_at。列表按 `sort, id DESC`。

### 后台（admin「景点」Tab）

- 列表：缩略、名称、slug、标签、排序、状态、查看页面；上/下线、编辑、删除二次确认（级联清理 R2 封面）
- 表单：名称*、slug*（`^[a-z0-9][a-z0-9-]{0,59}$`，唯一校验 409 dup_slug）、一句话简介*、标签、正文（textarea 空行分段）、地址/时间/门票/交通、封面（可选）、排序、状态
- API：`GET/POST /api/attractions`、`POST/DELETE /api/attractions/:id`、`PUT /api/attractions/cover`（复用 `uploadImageR2`，attra/c-* 前缀）
