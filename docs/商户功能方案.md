## 1. 目标与分工

| 面 | 位置 | 性质 |
|---|---|---|
| **公开展示** | `whizzzest.com/merchants/`（主 Worker 动态渲染） | 面向游客，SEO 收割（"万载 六大碗 餐厅"类搜索词），长在主域 |
| **商户门户** | `merchant.whizzzest.com`（新 Worker `whizzzest-merchant`） | 面向商户：入驻申请、登录、状态/编辑/数据看板。整域 noindex、独立会话限流，与主站/后台隔离（与 admin 同模式） |
| **站长管理** | `admin.whizzzest.com` 后台新增「商户」Tab | 审核（通过/驳回附原因）、等级、置顶、到期、核销标记 |

为什么展示页不跟门户一起放子域：展示页是内容资产，必须吃主域 SEO 权重；门户是登录型应用，天然隔离。商户内容是**数据库权威**（审核通过即时上线，不跑构建），主 Worker 在 assets 回退前拦截 `/merchants/*` 查 D1 渲染 HTML，边缘缓存 5–10 分钟。

## 2. 数据模型（D1 `whizzzest` 库）

```sql
CREATE TABLE IF NOT EXISTS merchants (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  slug TEXT UNIQUE,                    -- 详情页 /merchants/<slug>/，审核通过时生成
  name TEXT NOT NULL,
  category TEXT NOT NULL,              -- cuisine|stay|specialty|fireworks|other
  tier TEXT NOT NULL DEFAULT 'free',   -- free|verified|featured
  intro TEXT NOT NULL,                 -- 一句话简介（卡片用）
  detail TEXT,                         -- 详情（详情页用，纯文本分段）
  cover TEXT, images TEXT,             -- R2 对象键；images 为 JSON 数组
  address TEXT, phone TEXT, wechat TEXT, hours TEXT,
  contact_name TEXT, contact_phone TEXT,   -- 申请人（不对外）
  status TEXT NOT NULL DEFAULT 'pending',  -- pending|approved|rejected|expired
  reject_reason TEXT,
  paid_until TEXT,                     -- 付费展示到期日（NULL = 免费期）
  sort_weight INTEGER NOT NULL DEFAULT 0,  -- featured 置顶权重
  view_hint TEXT,                      -- 保留：营转数据如需脱离 visits 单算
  created_at TEXT DEFAULT (datetime('now')),
  updated_at TEXT DEFAULT (datetime('now'))
);

CREATE TABLE IF NOT EXISTS merchant_users (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  merchant_id INTEGER NOT NULL REFERENCES merchants(id),
  phone TEXT UNIQUE NOT NULL,
  email TEXT,                          -- M2.1：绑定邮箱（可空），绑定后可邮箱+验证码登录
  pass_hash TEXT NOT NULL,             -- PBKDF2-SHA256(每商户随机盐, 10万次)
  created_at TEXT DEFAULT (datetime('now'))
);
CREATE UNIQUE INDEX IF NOT EXISTS idx_mu_email ON merchant_users(email);

-- M2.1 邮箱验证码：6 位码存 SHA-256，10 分钟有效 ≤5 次尝试；purpose 区分 login/bind
CREATE TABLE IF NOT EXISTS email_login_codes (
  email TEXT PRIMARY KEY,
  code_hash TEXT NOT NULL,
  purpose TEXT NOT NULL DEFAULT 'login',
  expires_at TEXT NOT NULL,
  attempts INTEGER NOT NULL DEFAULT 0,
  created_at TEXT DEFAULT (datetime('now'))
);
```

图片：新 R2 桶（免费 10GB），门户 Worker 直传（multipart，校验类型 jpg/png/webp、单张 ≤5MB、每户 ≤9 张），公开读取走主 Worker 的 `/assets-merchant/<key>` 代理路由（带长缓存）——无需给 R2 挂自定义域名。

## 3. 公开侧（/merchants/）

- **目录页**：分类 Tab（全部/美食/住宿/特产/花炮/其他）+ 置顶推荐区（featured 大卡，按 sort_weight）+ 卡片网格（free 只显示名称/简介/分类徽标；verified 显示认证徽标 + 更多字段）
- **详情页** `/merchants/<slug>/`：封面 + 图集 + 详情 + 地址/电话（一键复制）/微信/营业时间 + 徽标 + 同类推荐 + 入驻 CTA 尾部
- 每页 `<link rel="canonical">`、进 sitemap（新增动态 `/merchants/sitemap.xml` 片段，robots.txt 加一行）、结构化数据 LocalBusiness
- 入口：导航栏「商户」项 + 首页中下部推荐板块（已拍板）
- 详情页浏览计入并行会话的 visits 采集，为 M3 商户数据看板铺底

## 4. 商户门户（merchant.whizzzest.com）

| 路由 | 功能 |
|---|---|
| `/apply` | 入驻表单（基本信息 + 分类 + 简介 + R2 传图 + 联系人 + 设置密码）→ 状态「待审核」 |
| `/login` | 双方式：手机号+密码 ／ 邮箱+验证码（M2.1，仅已绑定邮箱的账号） |
| `/dashboard` | 审核状态/驳回原因、编辑信息（内容字段改动 → 重新进入审核）、**页面访客统计**、到期与续费提醒、收款码、**账号安全**（绑定/更换登录邮箱） |

定价（占位，数字待定）：免费试用（3 个月基础卡片）→ 认证商户 ¥__/年（徽标+详情页+数据看板）→ 置顶推荐 ¥__/月（目录头部大卡+分类置顶）。

## 5. 站长后台扩展（admin Worker「商户」Tab）

待审列表（通过/驳回+原因）→ 通过即生成 slug 上线；商户列表（筛选状态/分类）→ 改等级、置顶权重、到期日、**核销标记**（登记转账金额/日期）；驳回原因回显到商户门户。

## 7. 安全要点

门户全程 noindex；密码 PBKDF2 哈希（WebCrypto）；登录/提交按 IP 限流 + Honeypot；上传校验 MIME/魔数/大小；会话沿用 HMAC 签名方案（独立密钥）；改内容重审防白嫖改版；门户不加 Cloudflare Access（面向公众，Access 仅限站长后台）。

**M2.1 补充**：验证码 6 位存 SHA-256（不存明文），10 分钟有效、≤5 次尝试、同邮箱 60 秒内不重发；发码 IP 限流 10 分钟 6 次；登录用途对未绑定邮箱恒返回成功（防枚举），绑定用途如实报错；成功即删码。
