## 2. M1 目录爬虫设计（本次实施）

```
发现/解析层   逐分类顺序翻页 → 正则抽取 (id, 名称) → html.unescape 清洗
状态层        SQLite（games 表 id 去重 + pages 表断点续爬/审计）
限速层        单 host 全局节流（默认 0.25s + 随机抖动，并发 4，超时 20s，3 次指数退避）
停止条件      404 ｜ 连续 2 页无新增 id ｜ 达到 --max-pages 上限
产出          games/crawled/catalog/{4399,7k7k}.csv + .jsonl + summary.md（分类计数）
```

- **技术栈**：Python 3.10+ 纯标准库（urllib/sqlite3/concurrent.futures），零第三方依赖；
- **7k7k 特殊处理**：标签页假分页 → 每标签只爬到「连续 1 页无新增」即止（4399 为 2 页）；标签名随 `/tag/` 索引一并解析，进 `categories` 字段；
- **用法**：`python games/tools/crawler/catalog.py --site all`（支持 `--test` 冒烟、`--cats`、`--max-pages`、`--delay`、`--export-only`）；
- **体量预估**：4399 ~5k 页 + 7k7k ~1.5k 页，约 30 分钟后台跑完，全程可断点续爬；
- 选名辅助：CSV 用 Excel 筛选即可；`summary.md` 提供各分类总量速览。

## 3. M2 精选下载器（用户选完名字后实施，待规划）

对精选清单逐款执行（复用整合方案 §1.6 去外链清洗标准）：

1. 解析播放页 → 定位 H5 入口 iframe；**判定非 H5（SWF/大页游）即跳过并记录原因**；
2. BFS 递归镜像游戏资源（HTML/JS/CSS/图/音/JSON），URL 重写本地化，扫描 JS 中的动态 chunk；
3. 兜底：Playwright 无头实跑录网络请求补漏（可选，届时再决定是否引入重依赖）；
4. 产物 → `games/crawled/<站>/<id>/` + metadata.json（预填 games.json 字段草案）→ 人工过收录 SOP。

工程规范沿用 M1：限速节流、Referer 防盗链对策（4399 CDN）、单文件 >100MB 跳过、断点续爬。
