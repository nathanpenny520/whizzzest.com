## 0. 已拍板决策（2026-09-09）

| # | 决策 |
|---|---|

## 1. 站点侦察结论（2026-09-09 实测）

| 项 | 4399 | 7k7k |
|---|---|---|
| 反爬 | 首页/列表页匿名可访问，普通 UA 即可 | 同左 |
| 分类列表 | `/flash_fl/<分类id>_<页码>.htm`，**真分页**（抽验第 800/1560 页内容不重复） | 分类目录 `index_N.htm` 为**假分页**（第 2+ 页内容与第 1 页相同）；真枚举走 `/tag/<id>/` 标签页（1130+ 个标签，单页 ~50 款） |
| 分类枚举 | 2 动作 / 3 体育 / 4 射击 / 5 益智 / 6 冒险 / 7 棋牌 / 8 策略 / 12 休闲 / 13 儿童 / 16 装扮 | 11 个拼音分类目录 + `/tag/` 索引页解析出的 1130+ 标签（取并集，非严格全量：各列表页含大量公共推荐块，去重后为真实覆盖） |
| 页容量 | ~100 款/页（益智类 1560+ 页） | ~50 款/页（去重前），页间重叠大 |
| 游戏标识 | `href="/flash/<id>.htm">名称`（纯数字 id；拼音 slug 为大页游，忽略） | H5：`h5.7k7k.com/...&tid=<id>` 锚文本即名称；PC：`/<id>.htm` |
| 编码 | **GBK** | UTF-8 |
| robots | 未禁 `/flash_fl/`（仅禁资源目录与 `_pc.htm`） | 未禁分类页（禁 `/classic/`、`/api/`、带 `?` 查询串——正好避开其 Flash 归档区） |

> 注：7k7k 分类页大量直接挂 `h5.7k7k.com` 移动端 H5 游戏，**天然契合决策①**；4399 目录不区分 SWF/H5，H5 与否在 M2 逐款解析播放页时判定，不满足即跳过。

## 2. M1 目录爬虫设计（本次实施）

```
发现/解析层   逐分类顺序翻页 → 正则抽取 (id, 名称) → html.unescape 清洗
状态层        SQLite（games 表 id 去重 + pages 表断点续爬/审计）
限速层        单 host 全局节流（默认 0.25s + 随机抖动，并发 4，超时 20s，3 次指数退避）
停止条件      404 ｜ 连续 2 页无新增 id ｜ 达到 --max-pages 上限
产出          games/crawled/catalog/{4399,7k7k}.csv + .jsonl + summary.md（分类计数）
```

- **技术栈**：Python 3.10+ 纯标准库（urllib/sqlite3/concurrent.futures），零第三方依赖；
- **7k7k 特殊处理**：标签页假分页 → 每标签只爬到「连续 1 页无新增」即止（4399 为 2 页）；标签名随 `/tag/` 索引一并解析，进 `categories` 字段；
- **用法**：`python games/tools/crawler/catalog.py --site all`（支持 `--test` 冒烟、`--cats`、`--max-pages`、`--delay`、`--export-only`）；
- **体量预估**：4399 ~5k 页 + 7k7k ~1.5k 页，约 30 分钟后台跑完，全程可断点续爬；
- 选名辅助：CSV 用 Excel 筛选即可；`summary.md` 提供各分类总量速览。

### 2.1 M1 落地结果（2026-09-09）

- **4399：179,855 款**（动作 584 / 体育 12,611 / 射击 12,276 / 益智 87,278 / 冒险 9,988 / 棋牌 1,069 / 策略 1,326 / 休闲 17,899 / 儿童 4,134 / 装扮 32,795，含跨类重复计数）。全程 ~5k 页约 13 分钟；「动作」类第 12 页起为 SEO 复读内容（抽验 p14/p15 库外新增为 0），「连续 2 页无新增」停止规则可靠；
- **7k7k：仅 84 款**。实爬发现其标签页/分类页服务端内容池极小（抽验 tag100≡tag500、tag777 与 tag100 44/46 重合），静态页面可见的游戏就这么多；真实全量目录在 `/api/` 后面且 robots.txt 明令禁止（`Disallow: /api/`），故到此为止。7k7k 仅作补充来源；
- 产物：`games/crawled/catalog/{4399,7k7k}.csv`（utf-8-sig，Excel 直接筛选）、`.jsonl`、`summary.md`、`catalog.db`（可断点续爬/重导出 `--export-only`）。

### 2.2 M1.5 候选池 H5 实测（2026-09-09）

- **判别链**（工具 `games/tools/crawler/verify_h5.py`）：播放页 `/flash/<id>.htm` 内嵌 `_strGamePath` → 真实游戏入口 = **`https://szhong.4399.com/4399swf` + `_strGamePath`**（该 CDN 前缀提取自 h.4399.com 移动播放页引用的 `/js/serverszhong.js`）→ 抓入口文件头嗅探：含 `.swf`/`swfobject` 为 Flash，含 `<html>`/`<script>` 为 H5（**扩展名不可靠**：`.htm` 后缀也可能是 H5）；
- 实测 679 款候选（关键词+近期高id+定向补验三轮），**605 款确认 H5**，写入 `catalog.db`（h5/gpath/gw/gh/gpic/gurl 列，含真实入口 URL 与画布尺寸，M2 直接复用）；74 款 Flash 淘汰（含 死神VS火影2.6/3.2 与 拳王Wing 全系——均为 Flash 无 H5 版，按决策①不收；系列仅「真死神VS火影绊」有官方 H5 化）；
- **精选 100 款**（`games/tools/crawler/shortlist.py` → `shortlist100.md/.csv`）：按类型准入矩阵分 14 组——逃离/密室解谜 15、文字/规则怪谈 5、魔塔 3、数字逻辑 11、棋牌桌游AI 10、汉字成语 7、找茬记忆连连 8、物理弹球 10、塔防PvZ系 5、STG弹幕 5、动作平台双人 11（含真死神VS火影绊/街机死神）、音乐猜歌 2、创意解压 5、轻模拟 3；2048 类按整合方案决策⑤不收（自研「花炮合合」占位）；
- 遴选标准：名气/系列质量 + 类型矩阵匹配 + 同质换皮去重（如「拯救X」「逃离X」系列只取代表作）。

### 3.1 M2 落地记录（2026-09-09）

- **工具链**（`games/tools/crawler/`）：`fetch_games.py`（BFS 镜像 + 资产嗅探 + 引用改写 + `document.domain` 中和 + gameIndex 壳解锁 + 断点续抓/审计）、`audit_mirrors.py`（离线引用完整性审计，断链自动分类「源站缺/我方漏抓」）、`repair_mirrors.py`（定向补抓）；
- **产物**：`games/crawled/games/<id>/`（`host/<域名>/<源路径树>` 镜像 + `metadata.json`：文件清单/sha1/真实入口 entry_local/未决外链/404 档案）——**100 款 / 2,853 文件 / 430MB**，最大件：真死神VS火影绊 45.5MB、PvZ泳池版 38.8MB、泡泡坦克3 25.9MB；
- **关键机制**：① h5mini 壳架构——入口 `index.html` 是空壳，真游戏在同目录 `gameIndex.html` 且有防盗链（需带入口页 Referer，误命中回 200「page err」占位页，已按内容识别）；② 游戏真实入口 = `szhong.4399.com/4399swf` + `_strGamePath`（来自移动播放页 `serverszhong.js` 的 `webServer`）；
- **事故与修正**（如实记录）：首版嗅探曾沿游戏内嵌的 4399 主站推荐位图链越界抓取（触及其 robots 禁爬路径 `/upload_pic/` `/userup/`）——已杀进程止损、作废重抓 73 款、抓取范围**硬锁**在「入口主机 + 游戏目录」并在审计中确认 0 越界；顺手挤掉全库约 90% 的体积水分（如上海麻将 62.5MB→3.2MB）；
- **已知边界**：源站死引用 1.07 万条（游戏数据表含未部署素材，运行时不会真正请求）不抓；>20MB 内嵌包的伪引用（`-this.obj` 类压缩码残片）约 966 条不抓，抽样证实均为源站 404；任何静态审计盲区由收录 SOP 的浏览器实机验收兜底；
- **下一步**：收录清洗（剥广告/SDK 外链，清单在每款 `metadata.json.unknown_external`）→ `upload-games.mjs` 传 R2 → games.json 登记 → **games.en.json EN 元数据同步登记（2026-09-10 增补，docs/游戏英文版方案.md §9；badge EN 统一译「Web classic」；批次一 5 款即漏做此步，欠账补录方案见彼处）** → `node game/scripts/check-i18n.mjs` 欠账过目 → 实机验收。

### 3.2 批次一实机验收与修复记录（2026-09-10）

- **新增工具链**：`browser-test.mjs`（无头 Chrome 实测：控制台错误/404/截图）、`interact-diag.mjs`（网格点击交互诊断）、`runtime-repair.mjs`（**运行时自愈**：实跑收集 404 → 同路径回源补抓 → 循环归零）。教训固化：**静态审计过不了的地方一律以真浏览器为准**；
- **两个深水区根因**（均已在管线修复）：① JS 运行时相对加载以**文档基**解析，静态嗅探须双基探测（resource 层整层漏抓的元凶）；② 引擎运行时**拼接文件名**（Unity `+ ".dat"`）静态不可知，靠运行时自愈兜底；
- **两个新认知**：① `.htm` 后缀曾因上传脚本/Worker MIME 表缺 `htm` 映射被当二进制流（导航中止）——双层已补；② 存在「**4399 自带 Ruffle 壳的 Flash 游戏**」（如密室逃脱3：壳为 H5、芯为 16.7MB SWF）——按决策①平台不引入 Ruffle 内核，但**包内自带 Ruffle 随游戏走**，视为可收录（games.json deviceNote 标注「Flash 内核（包内 Ruffle）」）；
- **垫片教训（反噬案例）**：clean_mirrors 曾给引用 h5api 的游戏注入 no-op 垫片——真死神VS火影绊的 `function.js` 本有 `if(!window.h5api) 走离线分支` 的防御，垫片让 `window.h5api` 存在反而使游戏进入「真 SDK 登录」分支死等回调、卡死标题。**教训：不要替游戏发明它没要求过的运行环境；「SDK 缺席」本身就是很多 4399 游戏的离线语义**。垫片已全面停用（clean_mirrors 仅剥外链标签），个别确需的游戏走 games.json 逐款配置；
- **淘汰记录**：数独 250482（Laya + h5mini postMessage 握手强耦合，标题后静默挂起）→ 已由 **4399-226392 智力数独（Well Sudoku）** 顶替，原包保留待专项适配；
- **批次一终态（全部真浏览器过验）**：真死神VS火影绊（Unity 258MB 数据包已入 UnityCache）/ 宠物连连看3.1 / 密室逃脱3（Ruffle 播 SWF）/ AI五子棋 / 智力数独——线上 games.json 16 款；upload-games.mjs 顺修文件名空格与 htm MIME 两个上传期 bug。

对精选清单逐款执行（复用整合方案 §1.6 去外链清洗标准）：

1. 解析播放页 → 定位 H5 入口 iframe；**判定非 H5（SWF/大页游）即跳过并记录原因**；
2. BFS 递归镜像游戏资源（HTML/JS/CSS/图/音/JSON），URL 重写本地化，扫描 JS 中的动态 chunk；
3. 兜底：Playwright 无头实跑录网络请求补漏（可选，届时再决定是否引入重依赖）；
4. 产物 → `games/crawled/<站>/<id>/` + metadata.json（预填 games.json 字段草案）→ 人工过收录 SOP（含 games.en.json 展示字段英译，见整合方案 §5 第 7 条）。

工程规范沿用 M1：限速节流、Referer 防盗链对策（4399 CDN）、单文件 >100MB 跳过、断点续爬。
